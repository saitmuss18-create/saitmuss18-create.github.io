YT Analytics Local

YT Analytics Local is a private, internal tool used by one creator to manage and analyse his own YouTube channels (Slow Light Science and One Paycheck Away). It runs only on the owner's computer.

With the owner's consent (Google OAuth 2.0), it uses the YouTube Data API and YouTube Analytics API to:

  • upload the owner's own videos and set their titles, descriptions and thumbnails;
  • read the owner's channel and video statistics and analytics reports;
  • read comments on the owner's own videos.

The tool is not offered to the public and does not access anyone else's channels.
